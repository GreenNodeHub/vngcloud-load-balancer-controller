<objective>
Fix noisy event handler logging across all controllers. Currently, many handlers log every
Create/Update/Delete event BEFORE checking filters (IsServiceSupported, IsIngressSupported, etc.),
producing log lines for events that are silently dropped. Move all log statements AFTER the
filter check so only events that actually get enqueued are logged. Standardize log message
format to "Enqueue {ResourceType} {namespace}/{name}" with V(1) verbosity.

Purpose: Reduce log noise in production — currently every Service/Node/Ingress/etc. event in the
cluster produces a log line even when the controller ignores it.
Output: All 19 eventhandler files updated with post-filter logging.
</objective>
