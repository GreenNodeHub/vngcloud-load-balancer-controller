## Changes Made

### genListenerName (both packages)

Old behavior:
- `if port.Name != "" -> "listener-{port.Name}"` (e.g. "listener-http")
- fallback: `"listener-{Protocol}-{Port}"` (e.g. "listener-TCP-80")

New behavior:
- Always: `"listener-{Port}"` (e.g. "listener-80")

### genPoolName (both packages)

Old behavior:
- `if port.Name != "" -> "pool-{port.Name}-{protocol}"` (e.g. "pool-http-tcp")
- fallback: `"pool-{Protocol}-{Port}-{protocol}"` (e.g. "pool-TCP-80-tcp")

New behavior:
- Always: `"pool-{Port}-{protocol}"` (e.g. "pool-80-tcp")
